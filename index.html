BREACH AWARENESS

What is a Password Breach?

⚠️

Data Breach

A data breach happens when unauthorized people gain access to protected information stored by a website or organization.

🔓

Exposed Password

If a password becomes exposed in a breach, attackers may try to use it to access accounts.

🛡️

Stay Protected

Use unique passwords, avoid password reuse and enable multi-factor authentication whenever possible.

SECURITY TIPS

Build Better Password Habits

01

Use Long Passwords

Longer passwords are generally harder to guess.

02

Use Unique Passwords

Avoid using the same password for multiple accounts.

03

Avoid Personal Information

Do not use easily guessable information like names or birthdays.

04

Enable MFA

Multi-factor authentication adds another layer of security to your accounts.
