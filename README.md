# Password Security Lab 🔐

Password Security Lab is a cybersecurity awareness project
designed to help users understand password strength and
basic password security practices.

## Team Members

- Komal
- Divashu

## Features

- Password strength analysis
- Password length checking
- Uppercase letter checking
- Lowercase letter checking
- Number checking
- Special character checking
- Password strength meter
- Security suggestions
- Password show/hide option
- Password breach awareness
- Cybersecurity security tips
- Responsive design

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

1. Download or copy the project folder.
2. Open the folder.
3. Open `index.html` in a web browser.

## Project Purpose

The main purpose of this project is to create awareness
about password security and help users understand the
characteristics of stronger passwords.
